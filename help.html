World Map — Help

Color the countries of the world by a number and share the result as a link.

Open the map

What it is

You enter a number for each country. Countries are colored on a gradient from the low color (smallest value) to the high color (largest value). Countries without a value get the no-data color.

The whole map is stored in the page link: the data, the units, the colors and the zoomed view. Nothing is saved on a server. Sharing the link shares the map exactly as you see it. Anyone who opens it can edit their own copy without affecting yours.

Using the map

Buttons (top-left)

  • Share (three connected dots): copies the current map link to the clipboard.
  • Edit (pencil): opens the edit panel. While editing, the icon is a check mark; click it again to finish.
  • Help (question mark): opens this page.

Entering values

  1. Click Edit.
  2. Click a country on the map.
  3. Type a number and press Save (or Enter). Remove clears the country's value. Escape closes the box.

Either . or , works as the decimal separator when you type, and negative numbers are allowed.

Edit panel

  • Units: text shown after every number, e.g. %, $, people (up to 20 characters).
  • Low / High / No data: the three colors. Reset colors restores the defaults (soft red → soft green, light grey).
  • Clear all data: removes every value.

Moving around

  • Zoom with the mouse wheel, a pinch, the + / − buttons (bottom-right) or the + / - keys. ⟲ or 0 returns to the whole world.
  • Drag to pan. The zoomed view is part of the link too.
  • Hover a country to see its name and value.

Numbers on the map and the bottom strip

Each value is written inside its country. When you zoom or pan, the number moves into the part of the country that is still on screen. When a number does not fit inside its country (small countries, or a zoomed-out view), it is listed instead in the strip at the bottom: a color square, the country name and the value, largest first. Zoom in and the number moves back onto the map.

The legend (bottom-left) shows the gradient with the minimum and maximum values.

Building a map link (for scripts and LLMs)

A map is fully described by the part of the URL after #. To create a map, build a link of this form and open it (or give it to a person):

https://<this-site>/#d=<key>:<value>,<key>:<value>&u=<units>&a=<hex>&b=<hex>&n=<hex>&v=<zoom>,<lon>,<lat>

Replace <this-site> with the host this help page is served from. Parameters are joined with &, in any order. Every parameter is optional. Leave one out to use its default.

ParamMeaningFormatDefault
dData: one value per countryComma-separated key:value pairs. key is a country key (see below). value is a plain number with . as the decimal separator, no thousands separators, may be negative or use exponent notation (1.5e9).no data
uUnits shown after each numberURI-encoded text, max 20 characters (e.g. %25 for %, people, %E2%82%AC for €)none
aColor of the lowest value6 hex digits, no #e57373 (soft red)
bColor of the highest value6 hex digits, no #81c784 (soft green)
nColor of countries without data6 hex digits, no #d3d3d3 (light grey)
vZoomed viewzoom,lon,lat. zoom is greater than 1 and at most 20. lon/lat (degrees) is the point shown at the screen center.whole world

Rules

  • Country keys are ISO 3166-1 numeric codes without leading zeros: Albania is 8 (not 008), Germany is 276, the USA is 840.
  • Three territories have no ISO code and use a lowercase name instead: ncyprus (Northern Cyprus), somaliland, kosovo.
  • Only the 176 countries listed below exist on the map. Very small countries (e.g. Singapore, Malta, Monaco, Bahrain, most island nations) are not drawn. Their keys are ignored. Antarctica is not shown.
  • The gradient is linear between the minimum and maximum of the values in d. If all values are equal, every country gets the middle color.
  • Pairs with a non-numeric value, colors that are not 6 hex digits and out-of-range views are ignored, as are unknown parameters. The map never fails to load because of a bad parameter.
  • If a key appears twice in d, the last one wins.

Examples

Population in millions for five countries, default colors:

/#u=M&d=156:1411,356:1428,840:335,76:216,276:84

Renders China, India, USA, Brazil and Germany. Germany (84) is the reddest, India (1428) the greenest. Every other country is grey, and the numbers show as e.g. 1,428 M. At the whole-world view Germany is too small for its number, so it is listed in the bottom strip.

Percentages with custom colors (white → dark blue):

/#u=%25&a=ffffff&b=08306b&d=250:72.5,724:68.1,380:63.9,826:75.4,56:70.2,442:81

France, Spain, Italy, UK, Belgium and Luxembourg, with units %. At the whole-world view these countries are too small for labels like 72.5 %, so all six are listed in the bottom strip.

Same map, zoomed into Western Europe:

/#u=%25&a=ffffff&b=08306b&d=250:72.5,724:68.1,380:63.9,826:75.4,56:70.2,442:81&v=5,5,47

Zoom 5, centered on 5° E, 47° N. Five numbers are now drawn on the map. Luxembourg is too small to hold its number at any reasonable zoom, so it stays in the bottom strip. Exactly what fits depends on the window size.
